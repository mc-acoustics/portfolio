# MC Engenharia Acústica — Portfólio digital

Site-portfólio mobile-first de Moisés Canabarro (MC Engenharia Acústica),
usado como cartão de visitas digital: QR code → Linktree → esta página.

- `index.html` — HTML único e standalone (~16 MB): fontes (Archivo + IBM Plex
  Mono) e fotos embutidas, bilíngue PT/EN via toggle, identidade visual
  "Petróleo & Terracota".
- Publicado via GitHub Pages.

Fonte editável do design e assets originais ficam fora do repo
(`IDENTIDADE VISUAL MC\cartao-digital\site\handoff\`).
